# ai-ml 용어집 (study 모드 전용)

형식: `용어 (한국어 의미): 한 줄 설명 — 예시`. 처음 등장할 때 1회만 사용한다.

- Reproducibility (재현성): 같은 코드를 실행하면 항상 같은 결과가 나오는 성질.
- Seed (시드): 난수 생성의 시작점. 같은 seed면 같은 난수열.
- Hyperparameter (하이퍼파라미터): 학습 전에 사람이 정하는 값 — epochs(전체 데이터 반복 횟수), batch_size(한 번에 처리하는 데이터 수), learning_rate(가중치 갱신 크기), optimizer(가중치 갱신 알고리즘).
- MLflow / W&B / DVC: 파라미터·지표를 기록 / 학습 곡선을 실시간 시각화 / 데이터·모델을 Git처럼 버전 관리하는 도구.
- Baseline (베이스라인): 비교 기준이 되는 최소 성능 모델.
- Overfitting (과적합): 학습 데이터에만 맞춰져 새 데이터에서 성능이 떨어짐 — train 99% / val 70%.
- Underfitting (과소적합): 학습 데이터도 못 맞춤 — train·val 둘 다 낮음.
- Dropout (드롭아웃): 학습 중 뉴런 일부를 무작위로 끄는 정규화 기법.
- Early Stopping (조기 종료): val loss가 개선되지 않으면 학습을 멈춰 과적합을 막는 기법.
- Class Imbalance (클래스 불균형): 클래스별 데이터 수 편중 — 정상 9,900 vs 불량 100이면 "항상 정상"도 정확도 99%.
- Precision (정밀도): 양성이라 예측한 것 중 실제 양성의 비율.
- Recall (재현율): 실제 양성 중 맞힌 비율.
- F1: Precision과 Recall의 조화평균.
- mAP: 객체 탐지의 종합 지표 (클래스별 AP의 평균).
- Inference (추론): 학습된 모델이 새 입력에 예측값을 내는 과정.
- Singleton (싱글턴): 객체를 하나만 만들어 재사용하는 패턴 — 모델 로드 3초면 요청마다 3초가 추가되므로 1회만 로드.
- Batch Inference (배치 추론): 여러 요청을 묶어 한 번에 처리해 GPU 효율을 높임.
- Tensor (텐서): 다차원 배열 — 이미지는 `(채널, 높이, 너비)`.
- Latency (지연시간): 요청부터 응답까지 걸리는 시간.
- Adversarial Input (적대적 입력): 사람 눈에는 같지만 모델을 오판하게 만드는 미세 변형 입력 — STOP 표지판을 속도제한으로 오인.
- EDA (탐색적 데이터 분석): 모델링 전에 데이터 분포·결측·이상치를 살펴보는 단계.
